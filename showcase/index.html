How the local agent works

Observe. Decide. Act.

01 / OBSERVE

Read the browser state

The agent reads interactive elements from the page’s DOM, preserving their identity and checking that the page has not changed before acting.

02 / DECIDE

Choose a structured action

Jev selects the next action. A separate text model handles generated text, such as a city name to type into a search field.

03 / ACT

Execute through Chrome

Python and browser-harness use a Chrome DevTools Protocol session to click, type, select and scroll. The local inspector shows state and action history.

Scope and limitations

  • The hosted page is static; no model or browser sessions run here.
  • The local tool is a search prototype, not a booking service.
  • Do not proceed to booking or payment without explicit human confirmation.
  • Recorded timings are not guarantees. Results depend on models, page behaviour and configuration.
  • The local agent’s loopback, origin and token safeguards remain unchanged.
